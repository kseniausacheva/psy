# Анна Соколова — психоаналитик

Одностраничный сайт практикующего психоаналитика.
Статический HTML/CSS/JS — без сборки, без зависимостей.

## Запуск локально

Просто открой `index.html` в браузере, или подними любой статический сервер:

```bash
npx http-server . -p 5173
```

## Структура

- `index.html` — разметка
- `styles.css` — Editorial Luxury палитра, double-bezel, кастомные cubic-bezier
- `script.js` — мобильное меню, scroll-reveal, magnetic CTA, parallax hero
